ربط حساب GitHub

تحتاج إلى إنشاء Personal Access Token من GitHub لربط حسابك.

خطوات إنشاء Token:

  1. اذهب إلى GitHub Settings → Tokens
  2. اختر Generate new token (classic)
  3. اكتب اسم للـ Token مثل git-zip
  4. فعّل الصلاحيات: repo (كامل)
  5. اضغط Generate token
  6. انسخ الـ Token والصقه هنا
